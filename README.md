# شريان الاختناق — إغلاق مضيق هرمز ومآلات التجارة العالمية

موقع وثائقي تحليلي متكامل يرصد التداعيات الاستراتيجية والجيوسياسية لإغلاق مضيق هرمز على تدفقات الطاقة وسلاسل الإمداد والاقتصاد الدولي، مستنداً إلى البيانات الرسمية الموثقة من إدارة معلومات الطاقة الأمريكية (EIA)، ووكالة الطاقة الدولية (IEA)، وتقارير لويدز البحرية، وصندوق النقد الدولي.

---

## البنية والتقنيات المستخدمة

- **الواجهة:** HTML5 دلالي متوافق مع معايير الوصولية العالمية ومحركات البحث (SEO/OpenGraph).
- **التصميم:** CSS مخصص من الصفر بتصميم مستوحى من هوية مشاريع خلدون عكرمة (الأسود الفاحم، الأزرق الفولاذي، وتوكن الذهب السيادي `#C9A557`).
- **التفاعل:** JavaScript نقي (Vanilla JS) بدون أي اعتماديات خارجية، يشمل معالجة التمرير التفاعلي وخريطة ملاحية تفاعلية ونموذج توثيق حقيقي عبر Web3Forms.
- **الخطوط:** 
  - `Cairo Bold` (عناوين)
  - `Tajawal Regular/Medium` (متن)
  - *ترخيص الخطوط:* مستضافة ذاتياً ومحلياً بصيغة `.woff2` تحت رخصة الخط المفتوح **SIL Open Font License (OFL)**.
- **الأصول السيادية:** 
  - شعار العقاب السيادي المعتمد بنسخته المعدنية المصقولة `brand/eagle-emblem-metal.svg`.
  - التوقيع المعتمد: `@𝓚𝓱𝓪𝓵𝓭𝓸𝓾𝓷𝓐𝓴𝓻𝓪𝓶𝓪𝓱` (بحرف 𝓐 واحد).
